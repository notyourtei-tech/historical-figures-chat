# Ancient Wisdom Chat

An AI-powered web application that lets you have real-time conversations with historical figures from around the world. Powered by large language models (via OpenRouter), each figure responds in character — with their own personality, philosophy, life story, and famous quotes.

## What It Does

- **Chat with 25+ historical figures** — Confucius, Socrates, Einstein, Shakespeare, Sun Tzu, Leonardo da Vinci, Li Bai, Napoleon, and many more.
- **Authentic AI responses** — Every reply is generated by a real AI model, not hardcoded templates. The system prompt injects each figure's biography, philosophy, and speaking style so the AI responds in character.
- **MBTI personality matching** — Take a quick MBTI quiz and get personalized recommendations for which historical figures best match your personality type.
- **Multi-language support** — Chat in Chinese, English, Japanese, Vietnamese, or Burmese. Each figure responds fluently in the selected language.
- **Chat history** — Conversations are saved locally in your browser so you can pick up where you left off.
- **Emotional companion mode** — Figures are guided to listen empathetically, offer wisdom from their life experiences, and help you reflect through Socratic dialogue.

## Getting Started

1. **Clone the repo**
   ```bash
   git clone <your-repo-url>
   cd historical-ai-platform
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure API key**
   ```bash
   cp .env.example .env.local
   ```
   Edit `.env.local` and add your [OpenRouter API key](https://openrouter.ai/keys):
   ```
   OPENROUTER_API_KEY=your_key_here
   ```

4. **Run the dev server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## How It Works

Each historical figure has a detailed knowledge profile stored in the codebase — their life story, famous quotes, works, and core philosophy. When you start a chat, the app constructs a system prompt that tells the AI model:

> "You are Confucius. Here is your life story, your philosophy, your quotes. Respond as Confucius would."

The AI then generates all responses in character. There are **zero hardcoded replies** — every message you see is produced by the AI model in real time.
